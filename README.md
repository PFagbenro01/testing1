# Java Programming Assignments

This folder contains three console-based Java programs:

- `SchoolGradingSystem.java` calculates a letter grade and reports pass/fail status.
- `ATMSimulator.java` verifies a PIN, starts with a `$5000.00` balance, and supports balance checks, deposits, withdrawals, and exit.
- `PasswordStrengthChecker.java` reports each password requirement and classifies the password as `WEAK`, `MODERATE`, or `STRONG`.

## Run a program

From this folder, compile the files with:

```text
javac SchoolGradingSystem.java ATMSimulator.java PasswordStrengthChecker.java
```

Then run one program with:

```text
java ATMSimulator
```

The ATM demo PIN is `1234`.
